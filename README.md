# KDE Plasma Themes

This repository contains two user-installable theme collections for KDE Plasma 6:

- [Nevermore](Nevermore-KDE-Plasma6-v1.0/README.md) — a Gothic-inspired desktop theme with coordinated icons, wallpapers, window decorations, Konsole styling, splash assets, and installer scripts.
- [The Department of Questionable Decisions](Department-Questionable-Decisions-KDE-Plasma6-v1.0/README.md) — an office-bureaucracy-inspired theme with coordinated desktop styling, wallpapers, Konsole integration, and installer scripts.

## Installation

Open the README in the theme folder you want and follow its installation steps. Each theme installs into the current user's KDE configuration and data directories; run its installer as your regular user, without `sudo`.

## Repository layout

Each versioned folder is a self-contained theme package. It includes its own installer, uninstaller, assets, and usage notes. This repository is licensed under [GPL-3.0-or-later](LICENSE).

## Compatibility

These themes target KDE Plasma 6 on Linux. Refer to each package README for tested environments and component-specific notes.
